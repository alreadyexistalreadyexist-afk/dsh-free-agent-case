# Примеры правок конфигов (обезличенные)

Эти правки нужны на шагах 11 и 15 инструкции ([docs/instrukciya.md](../docs/instrukciya.md)).
Ниже показано, как выглядят файлы **после** правки. Это образцы для сверки —
копировать их целиком в свои файлы не нужно, у вас уже есть своё содержимое.

## 1. `pnpm-workspace.yaml` — блок `allowBuilds` (шаг 11)

После правки последние строки файла выглядят так:

```yaml
allowBuilds:
  '@google/genai': false
  protobufjs: false
```

Смысл: pnpm не запускает служебные скрипты двух транзитивных зависимостей,
они ему не нужны. Без этой правки установка плагина моделей завершается
строкой `ERR_PNPM_IGNORED_BUILDS` и «упав, встаёт» — экран выглядит успехом,
а плагин не работает.

## 2. `package.json` — плагин моделей в списке `bundles` (шаг 11)

Список `bundles` находится ниже списка `dependencies`, в самом конце файла.
После правки в нём появляется строка плагина моделей (обратите внимание на запятую):

```json
"bundles": [
  "@deepseek-ai/dsh-web-app",
  "@opencode2dsh/dsh-plugin",
  "...остальные строки без изменений..."
],
```

Строки выше и ниже — это пример-заглушка; у вас в файле будут свои имена пакетов.
Добавляется только одна строка: `"@opencode2dsh/dsh-plugin",`.

## 3. `cordis.patch.yml` — регистрация MCP Manager (шаг 15)

Три строки добавляются в **самый конец** файла `%USERPROFILE%\.dsh\profiles\web\cordis.patch.yml`,
после уже существующего содержимого (его не трогаем):

```yaml
- insert:
    - id: mcp-manager
      name: 'dsh-mcp-manager'
```

После этого пункт **MCP Manager** появится в настройках веб-страницы DSH (настраивается
на шаге 16 инструкции).
