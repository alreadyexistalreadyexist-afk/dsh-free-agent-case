# Обновление от 13 октября 2026: что изменилось

Кейс был написан и работал на бесплатном OpenCode Zen через DeepSeek Harness.
С 23 сентября 2026 года OpenCode закрыл анонимный бесплатный тир для всех
сторонних клиентов. Это не сломало сам кейс, но изменило способ подключения.

## Что перестало работать

Прокси zengate больше не проходит гейт Zen. curl к нему возвращает 200 OK,
но запросы из DSH падают с 400 / 403 FreeTierError. Причина: Zen проверяет
не только заголовки, но и TLS-фингерпринт официального клиента, а также
канонический набор инструментов в запросе. DSH отправляет свои инструменты,
и Zen их отвергает.

Плагины-адаптеры (dsh-opencode-xdbridge, dsh-connect-opencode-free,
dsh-preset-tool-guard, dsh-mcp-proxy, @aiwayds/dsh-mcp-adapter,
@aiwayds/dsh-llm-net-retry, dsh-opencode-patch) — все удалены, ни один
не обходит гейт.

Подделка заголовков (User-Agent, x-opencode-session, stream, набор
инструментов) — не помогает. Гейт находится ниже HTTP-уровня.

Формулировка отказа от Zen (дословно):

> «OpenCode's free tier can only be used from within OpenCode.
> Download it at https://opencode.ai and keep building.»

Отдельно: у части моделей Zen есть региональное ограничение — из России они отвечают
`RegionError: This model is not available in your country`. Это ограничение каталога,
а не блокировка сети — оно не мешает кейсу, потому что рабочая модель big-pickle была
доступна. Если какая-то модель не отвечает, выберите другую из списка.

## Что работает вместо этого

**1. Платный API-ключ OpenCode Zen ($20 prepaid).**
Зарегистрироваться на opencode.ai/auth, получить ключ, использовать как
обычного провайдера в DSH через llm-pi-ai. Ключ работает через отдельный
канал, который не блокируется. Это самый простой путь — не требует ни
прокси, ни плагинов, ни костылей.

**2. Go-провайдер (dsh-opencodego, по подписке).**
Работает стабильно, без сюрпризов. Использовать для задач с MCP.

**3. Другие провайдеры с честным free tier.**
Groq, Cerebras, OpenRouter, NVIDIA NIM — у них нет такого гейта. Groq — 14 400 запросов/день, Cerebras — 14 400/день, OpenRouter — 50/день (бесплатный тир). Регистрация требует только email.

## Что осталось в кейсе

Всё остальное — архитектура, логика, MCP-серверы, сценарии — осталось
без изменений. Кейс по-прежнему актуален, просто способ подключения
к моделям теперь другой: не бесплатный Zen через прокси, а платный ключ
или Go-провайдер.

## Краткая сводка изменений

| Было (до 23.09.2026) | Стало (с 13.10.2026) |
|---|---|
| zengate + бесплатный Zen | Платный ключ Zen или Go-провайдер |
| agent-default-model: zengate/big-pickle | agent-default-model: opencode-go-native/glm-5.3-flash |
| summaryModel: big-pickle | summaryModel: glm-5.3-flash |
| Плагины-адаптеры для обхода гейта | Не нужны (ключ работает напрямую) |

## Обновление от 20 октября 2026: бесплатный канал снова работает

Ситуация изменилась с 13 октября. Команда плагина opencode2dsh разобрала новый гейт
OpenCode и выпустила версию 0.3.13 (19.10.2026), при которой бесплатный анонимный
канал снова работает из сторонних клиентов. Проверено сквозным прогоном из DSH
20.10.2026: запрос «pong» — ответ получен за 11 секунд, каталог жив (85 моделей,
`big-pickle` на месте), сам гейт OpenCode при этом никуда не делся — запрос без
инструментов по-прежнему получает 403 FreeTierError. Работает именно плагин.

### Что нужно сделать (одна команда)

Обновите плагин в профиле web до версии не ниже 0.3.13:

```sh
dsh plugin --profile web add @opencode2dsh/dsh-plugin@0.3.13
```

Перезапустите `dsh web` и выберите в списке моделей провайдер `opencode2dsh` →
модель `big-pickle` (это шаг 14 кейса).

Если установка завершается строкой `ERR_PNPM_IGNORED_BUILDS` — это известная
особенность (шаг 11 кейса): нужны обе правки из
[examples/primer-pravok.md](examples/primer-pravok.md), затем повторите команду.

Проверить, что канал жив, не проходя кейс: файл `~/.opencode2dsh/adapter-status.json`.
Плагин обновляет его сам при каждом запуске DSH. Здоровый вид:

```json
{
  "status": "ready",
  "total": 85,
  "lastError": ""
}
```

Пустой `lastError` и свежая дата — каталог получен с живого канала.

### Что происходило (коротко, по датам)

Гейт — не поломка и не сетевая блокировка: OpenCode намеренно пускает бесплатный
тир только через собственный клиент и трижды ужесточал проверку формы запроса.
Комьюнити плагина каждый рубеж расшифровывало и выпускало фикс:

- 16.09 — сессия только канонической формы `ses_*`; простой подмены User-Agent
  больше недостаточно.
- ~09.10 — проверка заголовков сессии, `stream: true` и агентного набора
  инструментов (`bash` + `read`) → фикс v0.3.11 (11.10).
- ~13.10 — 12 шестнадцатеричных символов `ses_`-идентификатора проверяются как
  инвертированный таймстамп с счётчиком ≤ 63; шаблонные хеши проходят лишь в
  ~1,5 % случаев → фикс v0.3.12 (14.10).
- ~15.10 — смена поверхности запроса, запрет лишних заголовков, обязательные
  новые заголовки сессии, реальные схемы инструментов → фикс v0.3.13 (19.10).

Догадка про «TLS-отпечаток» из первых баг-репортов не подтвердилась: запрос с
правильной формой проходит с обычным HTTP-клиентом.

### Оговорки (честно)

- 403 бывают перемежающиеся: плагин сам делает один повтор на «сестринском»
  адресе. Если текст ошибки упоминает «abusive traffic from this IP» — ваш IP
  заблокирован целиком, поможет только смена сети или ожидание.
- Регион: `muse-spark-*` недоступны из России (RegionError); `jev-1.13-free`
  умер насовсем; реальный контекст `deepseek-v4.1-flash-free` ~300k токенов,
  а не миллион.
- Канал бесплатный и общий: при 429 плагин молча перетраивает (до ~90 секунд
  на шаг). Для тяжёлой нагрузки есть IP-пул в настройках плагина.

### Сводка «что сейчас»

| Что | Состояние после v0.3.13 |
|---|---|
| Бесплатный анонимный канал | **Работает** — обновите плагин до ≥ 0.3.13 |
| Бесплатная модель `big-pickle` (шаг 14) | Работает |
| Платный ключ Zen (обновление от 13.10 ниже) | Не требуется; остаётся запасным вариантом |
| Go-провайдер | Не затронут, продолжает работать |

плагина (≤ 0.3.9). На версиях ≥ 0.3.13 они сняты.
