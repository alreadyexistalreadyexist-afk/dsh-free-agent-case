# Скриншоты

В этой папке публикуются скриншоты, подтверждающие результат кейса. Они добавляются
вручную, после просмотра автором: в автоматической подготовке содержимое изображений
не проверялось.

Рекомендуемые скриншоты:

1. `01-powershell-dsh-version.png` — окно PowerShell с успешно выполненной командой `dsh --version`.
2. `02-web-chat.png` — страница агента в браузере (⚠️ на скриншоте адресная строка должна быть
   скрыта или обрезана: в конце адреса служебный хвост после `?`).
3. `03-mcp-manager.png` — раздел Settings → MCP Manager со статусом `Connected` сервера `word-live`
   (⚠️ свернуть или скрыть любые персональные данные).
4. `04-word-result.png` — документ Word с двумя абзацами, написанными агентом
   («Привет! Это первая строка, которую написал мне агент.» и «Второй абзац. Я тоже написан агентом, не человеком.»).

Прежде чем публиковать любой скриншот, вручную проверьте его на:
личные данные, открытые документы с содержимым, адресные строки браузера,
имена пользователя в путях, EXIF-данные (GPS, имя устройства).
